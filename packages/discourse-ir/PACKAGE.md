# discourse-ir

Status: **prototype / PARTIAL**. Implements T121–T124 foundations: graph-structured DiscoursePlan, ClausePlan, semantic rhetorical relations, prerequisite-aware content selection, and hard/soft discourse ordering. Dialogue state, pragmatic planning, reference generation, aggregation, and broad realization remain incomplete.


T381-T390 research-expansion candidate adds:

- explicit information-structure overlays for topic/focus/given/new/contrastive focus;
- a topic stack whose activation is independent from entity-recency scoring;
- focus-sensitive operator association data;
- an inspectable discourse-relation registry and graph validator;
- paragraph/multi-paragraph planning contracts;
- semantic redundancy detection and generated contradiction checks;
- explicit enumeration/list semantics;
- deterministic multi-paragraph coherence benchmark coverage.
