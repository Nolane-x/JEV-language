# formal-ir

Status: **prototype / PARTIAL**.

Implemented in this wave: typed Data IR, Schema IR, Query IR, Math IR, Logic IR, Command IR, deterministic validators, read-vs-mutation query safety, and deterministic JSON renderers for the supported subsets. This advances T239–T244, T246–T247 and M15, but broader backends, richer unit/dimension semantics, and solver-backed logic remain open.
